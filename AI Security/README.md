# AI





|المصطلح|هو إيه؟|مثال|
|---|---|---|
|**LLM**|**نوع من الـModels**|GPT, Claude, Gemini|

|**Function Calling / Tools**|**Capability / Integration**|جعل الـLLM يستدعي API|
|**Agents**|**Architecture / System**|AI يخطط ويستخدم tools لتحقيق هدف|
|**Fine-tuning**|**طريقة لتعديل/تخصيص Model**|تدريب model على أمثلة خاصة|
